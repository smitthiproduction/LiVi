# LiVi — application iPhone et Android

Expo + React Native. iOS en priorité (lancement juillet 2027), Android et pliables en 2028 avec le même code.

- Règles de développement : [CLAUDE.md](CLAUDE.md)
- Formats d'écran : [../../docs/design/responsive-et-formats.md](../../docs/design/responsive-et-formats.md)
- Authentification : [../../docs/architecture/authentification.md](../../docs/architecture/authentification.md)

État : squelette navigable (onglets adaptatifs, connexion Apple, Google et e-mail, base locale chiffrée, fiche par classe, recherche, globe 3D/2D, bandeau de maintenance, écran de test). Les écrans métier sont à construire module par module en suivant le catalogue.
