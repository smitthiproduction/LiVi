# Politique de sécurité

## Signaler une vulnérabilité

Merci de ne pas ouvrir de ticket public. Utiliser le signalement privé de GitHub : onglet **Security** du dépôt › **Report a vulnerability**. Indiquer la surface (iPhone, web, back-office, API), les étapes de reproduction et l'impact estimé.

Engagements : accusé de réception sous 3 jours ouvrés, évaluation sous 10 jours ouvrés, correctif selon la gravité, crédit au déclarant s'il le souhaite. Aucune poursuite pour une recherche de bonne foi qui n'accède pas aux données d'autres utilisateurs et ne dégrade pas le service.

## Versions suivies

Seule la dernière version publiée de chaque application reçoit des correctifs de sécurité.
