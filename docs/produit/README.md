# Produit

LiVi est une application de suivi de patrimoine (iPhone d'abord, puis Android ; web ; back-office) qui rassemble budget, comptes, placements et biens, sans jamais vendre de produit financier ni recommander de placement.

## Principes non négociables

1. **Neutre** : aucun conseil, aucune suggestion maison, aucun bouton « Acheter » ou « Vendre ». LiVi IA exécute les consignes écrites par l'utilisateur, validées une par une.
2. **Local d'abord** : données sur l'appareil, chiffrées ; sauvegarde et synchronisation chiffrées de bout en bout en option.
3. **Rien sans aperçu** : import, propagation de catégorie, consigne, modification en masse.
4. **Fraîcheur et sources visibles** : chaque chiffre dit d'où il vient et de quand il date.
5. **Coûts visibles** : le coût de LiVi IA est affiché en euros.
6. **Accessible partout** : trois apparences (sombre, clair, pastel), tous les formats d'écran, lecteurs d'écran.
