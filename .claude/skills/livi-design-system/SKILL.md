# Appliquer le design system

## Liste de contrôle
- [ ] Aucune couleur, taille ou rayon en dur : jetons `@livi/design-tokens` (TS) ou variables `--lv-*` (CSS).
- [ ] Rendu vérifié en sombre, clair et pastel.
- [ ] Montant héros avec décimales et devise réduites ; chiffres tabulaires dans les listes.
- [ ] Gains et pertes : couleur + signe + flèche.
- [ ] Cartes opaques ; verre seulement pour les contrôles flottants.
- [ ] Ton : vouvoiement, infinitif sur les boutons, pas de point d'exclamation ni d'emoji, nombres à la française.
- [ ] Source et fraîcheur sous les chiffres.
- [ ] Formats : compacte, moyenne, étendue ; pliable externe, passeport et déplié ; paysage si graphique (`docs/design/responsive-et-formats.md`).
- [ ] Accessibilité : libellés de lecteur d'écran, texte agrandi jusqu'à 200 %, cibles de 44 points, contraste ≥ 4,5:1, « Réduire les animations » respecté.
